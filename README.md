# Your Jee Dashboard

A lightweight, mobile-first study dashboard built for JEE aspirants. Spine keeps your
preparation in one place: what to study today, what you've finished, and where you keep
losing marks.

## Features
- **Today's brief and daily rhythm**: a plan for the day with time blocks and tasks
- **Focus timer**: Pomodoro-style sessions logged by subject
- **Syllabus and lecture tracking**: chapter-wise progress, recorded lecture lists,
  topics and backlogs with priorities
- **Mistake notebook**: log errors, spot patterns, and mark them revised
- **Mocks**: record scores and review them against your goal
- **Weekly review and timeline**: time by subject and a study heatmap
- **My library**: quick links to study material
- **Calm mode** and light/dark/auto themes
- **Accounts and profile**: sign in/sign up, editable details, exam countdown
- **Backup and share**: download a backup of your data or share your progress

## Tech
- Plain HTML, CSS and vanilla JavaScript in a single `index.html`, with no build step
- Data stored locally via `localStorage`
- Authentication through Netlify Identity
- Responsive, installable-feel layout with a bottom navigation bar

## Run locally
Open `index.html` in a browser, or serve the folder with any static host
(GitHub Pages, Netlify, etc.).
